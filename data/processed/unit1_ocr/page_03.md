3. Process of Communication

### 3.1 What is Process of Communication?

* Process of communication refers to the step-by-step sequence of activities through which a message is created, encoded, transmitted, received, decoded and understood by the receiver.
* It is a continuous and dynamic process that involves two or more people and takes place through a particular medium with a specific purpose.

**Key Points:**
* It is a continuous process.
* Involves sender and receiver.
* Uses a medium or channel.
* Includes encoding and decoding.
* Feedback is an important part.
* Affected by noise or barriers.
* Purpose is to achieve mutual understanding.

### 3.3 Explanation of Each Step

| Step | Description | Example |
| --- | --- | --- |
| 1. Sender (Source) | Person who initiates the communication. | Teacher explaining a topic |
| 2. Idea / Thought | The idea, information or thought to be conveyed. | Concept of data structures |
| 3. Encoding | Converting the idea into a message using language, symbols or gestures. | Using simple language and diagrams |
| 4. Message | The actual content to be communicated. | Explanation with examples |
| 5. Channel / Medium | The means through which the message is sent. | Face-to-face, email, phone, etc. |
| 6. Decoding | Interpreting the message by the receiver. | Student understands the explanation |
| 7. Receiver (Destination) | Person who receives and interprets the message. | Student |
| 8. Feedback | Response from the receiver which indicates understanding. | Asking questions, nodding, replying |
| 9. Noise | Any barrier or interference that affects the message. | Background noise, poor network, etc. |

### 3.5 Features of the Process

① It is a two-way process.
② It is a continuous and ongoing process.
③ It involves encoding and decoding.
④ Feedback is an essential part.
⑤ It uses a medium or channel.
⑥ It can be affected by noise or barriers.
⑦ It requires a common understanding between sender and receiver.
